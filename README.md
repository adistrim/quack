# Quack Search

DuckDuckGo web search library for JS runtimes, written in Go

### Usage

```ts
import { search } from 'quack-search';
console.log(await search('golang', { maxResults: 5 }));
```

### Installation

```bash
bun add quack-search
# or
npm install quack-search
# or
yarn add quack-search
```
